# Region type native adapter

This directory contains original MIT-licensed Framework adapter code. ABI, native ownership and member-layout evidence comes from released Multiplayer REA commit `8a13602`, principally `src/game/region_properties_runtime.inc`, `src/game/mixed_path_reader.h` and `src/game/connected_network_reader.h`. It does not include Multiplayer transport or hook code.

The exact pristine `MT2.exe` SHA256 is `bbab2dc68babcc644d0a1679548bf1e334b6c52aea669c3f61f6cb9d45c1aaf6`. `native_evidence.json` retains complete PE exception-directory function extents and SHA256 digests for directly invoked entries. The common verifier also checks the current owned route composition.

`regions.set_type` uses a fresh private native Lift behavior, its original Press and Release, and its original destructor and sized delete. The only adapter write is the mode byte in that fresh private allocation. The transaction requires the exact saved Region handle, the actual root view Shard, an unowned Region, a different requested type and a hit which resolves to the selected Region. It does not open native UI or patch live Region fields.

Before Release, the adapter captures the complete native Region record and SaveContext ownership graph. It identifies every registered inline object below each manager that the original ClearContents visits. Typed Building and all 47 Scenery category rosters, saved-region mixed Path/Intersection ownership, Network topology and global Scenery Groups cross-check that census. This is an original adapter implementation using native serialization. It is bounded to 4096 saved Regions, 100000 records, 1000000 tokens or roster members and 32 MiB of record text. A missing serialization owner or unsupported shape fails with its actual cause before Release.

Readback checks cleared manager families, every retired full UID lookup, reciprocal surviving mixed Path and Network edges, unchanged surviving geometry/definitions/connections, original Group identities/poses and remaining relative member poses. Cross-Region segment or connected-node retirement must stay within the captured affected closure. The complete financial record, all 20 category counters, edit depth and native Undo stack transition are checked. Private witnesses contain native pointers; the public result contains only typed handles, Region details, counts and financial values.

Static native analysis is retained under `artifacts/region-type-checks/`. The original Release calls ClearContents before adding ClearRegion, PaintMapTerrain and ConfigureRegion inverses when lowering; raising adds ConfigureRegion. SetType also invokes ClearContents. ClearRegion stores the Region pointer and its Do calls ClearContents. ConfigureRegion stores type, levels, ownership, styles and tint. PaintMapTerrain stores the four original style polygon shapes. None of those three constructors stores a serialized whole-Region content record. The adapter checks those exact original payloads and does not manufacture extra inverses.

Scenery RemoveAll directly invokes deleting destructors. Scenery destruction reaches Prop destruction, Group NotifyPropDestroyed, RemovePropEvent dispatch, selection cleanup and the native UID registry removal. NotifyPropDestroyed removes the Group member record and preserves the Group itself. Event dispatch can invoke current subscribers. The absence of a per-Scenery Make operation in RemoveAll alone does not prove all possible native event behavior. Consequently the result reports `native_undo_operations`, not a blanket assertion that Undo restores every previous UID or all generated Region appearance/name state. Native history remains the original game behavior.

Validation is isolated MSVC compilation and synthetic typed tests. Tests prohibit all native invocation and cover integer/type domains, retirement family overlap, original polygon vector extents, cross-Region edge closure, surviving geometry, Group membership and stale handles. No game process, UI or save was mutated. Live runtime acceptance remains with the runtime owner.
